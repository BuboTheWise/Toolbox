# Agent Roles

## Cthugha
Primary implementation agent. Handles complex development tasks and architectural decisions.

## Bubo
Parallel execution agent. Focused on reliable, scoped task completion. Runs on BC-250 hardware.

## Glaux
Parallel execution agent (second BC-250). Same role and constraints as Bubo.

## Nyarlathotep
Coordinator and orchestrator. Manages work routing, atomic card creation, and board state.

## Grok
High-level design, assessment, and GitHub issue work. Not assigned implementation tasks.
